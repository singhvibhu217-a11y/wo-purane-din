## 📖 About The Project

**Wo Purane Din** is a retro-themed web application created to celebrate the iconic music of the 1980s and 1990s. With a sleek dark luxury UI, warm vintage aesthetic, and smooth playback controls, it brings back unforgettable memories through curated playlists, golden hits, and timeless memories.

---

## ✨ Key Features

- **📻 Vintage Aesthetics:** Elegant dark-purple & gold theme featuring classic gramophone imagery and retro typography.
- **🎧 Seamless Audio Player:** Built-in player with play/pause, dynamic progress tracking, volume control, and track information.
- **🎶 Curated Playlists:** Easily browse top classics, nostalgic hits, and memorable playlists from the 80s and 90s.
- **📱 Fully Responsive:** Optimized for desktop, tablet, and mobile viewing.
- **⚡ Fast Performance:** Lightweight and deployed globally on Vercel for instant load times.

## 🛠️ Built With

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Styling:** Custom CSS / Modern Responsive Layouts
- **Hosting & Deployment:** [Vercel](https://vercel.com)

## 🚀 Quick Start (Local Setup)

To get a local copy up and running, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/singhvibhu217-a11y/wo-purane-din.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd wo-purane-din
   ```

3. **Open the app:**
   Simply open `index.html` in your browser or run a live server extension in VS Code.
